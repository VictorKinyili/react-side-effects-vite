# React Side Effects: Programming Joke App

A React application that fetches and displays random programming jokes from JokeAPI using `useState` and `useEffect`.

## Features

- Automatically fetches a programming joke when the page loads using `useEffect`.
- Displays a loading message while waiting for the API response.
- Allows users to fetch a new joke by clicking a button.
- Handles failed API requests cleanly.

## Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone <your-github-repo-url>
   cd <repository-folder-name>
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

## Running Tests

Run the test suite to verify functionality:
```bash
npm run test
```
